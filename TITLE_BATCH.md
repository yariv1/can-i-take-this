# Title and meta description batch (2026-10-07)

**Why:** the GSC export (Aug 10 - Oct 4) shows many programmatic pages on page 1 (position 5-12) with 0-1 clicks. The meta descriptions of airline and country category pages were the calculator's default verdict ("Yes - carry it on. 100 ml is within Qantas's 100 ml limit.") and often did not name the airline or country. Descriptions now start with the subject and give the real answer from the page data; titles carry a number only when the page data has a verified one.

**Rules in the templates**
- Description = subject + topic + year, then the verdict head and the first rule line from the data, cut at a sentence end at 158 characters.
- Power bank title: "Max N, X Wh" only when the verified rule has both; Wh limit only when it has one; otherwise unchanged.
- Tobacco title: cigarette count only from a specific allowance line, never from the generic placeholder "(often ~200 cigarettes)".
- Cash title: threshold only when the data states one ("Declare EUR 10,000 or More").
- Plants & seeds title is a question ("Can You Bring Seeds & Plants into X? Permit Rules (2026)"), matching queries like "can i bring seeds ... into india".
- Food description states the real result (some banned / some need a declaration / most allowed).
- Liquids title says "100 ml Limit" (every airline page uses the 100 ml verdict).
