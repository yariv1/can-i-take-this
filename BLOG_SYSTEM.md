## Architecture

### How pages are generated
- `build.js` runs `node build.js` → generates all static HTML
- Blog pages go through `guideShell(o)` — same shell as `/guides/`
- Body content lives as inline JS string vars (`BODY_BLOG_INDEX`, `BODY_PB_ARTICLE`, etc.)
- All blog entries live in the `GUIDES` array (line ~945), processed by `GUIDES.forEach`
- Sentinel: `/*BLOG_V1*/` guards the blog patch (idempotent)

### URL structure
```
/blog/                                      → blog hub index
/blog/power-bank-rules-2026-crackdown/     → article #1
/blog/[slug]/                              → future articles
```

### Files that matter
```
build.js                    ← the only file you edit/run
articles/[slug].md          ← source notes (NOT read by build — for reference only)
assets/blog/[image].webp    ← ALL blog images live here
BLOG_SYSTEM.md              ← this file
ARTICLE_TEMPLATE.md         ← copy for every new article
sitemap.xml                 ← auto-generated by build.js
```

## guideShell(o) — what it expects

```js
{
  url:   '/blog/my-slug/',
  slug:  'my-slug',
  title: 'SEO title | canitakethis.co',
  desc:  'Meta description, ~150 chars',
  h1:    'Page H1 (displayed)',
  body:  BODY_MY_ARTICLE   // HTML string var defined above GUIDES array
}
```

guideShell provides:
- Full `<head>` with GA, AdSense, canonical, OG tags, theme guard
- Topbar (logo + theme toggle)
- `<main class="prose">` wrapper with `<h1 class="guide-h1">`
- Footer with guides + trust nav (includes Blog link)
- Theme toggle script + feedback.js

### BLOG HUB COMPONENTS


```html
<div class="cat-label">✈ Batteries &amp; Electronics</div>
```

#### Featured card (hero — one per category, full-width)

## Adding a new article — checklist

1. Write body HTML using components above → store as `BODY_[NAME]` var in build.js before `/*GUIDES_V1*/`
2. Add entry to `GUIDES` array
3. **Update IMAGE REGISTRY above** — add all new image filenames + status
4. **Update hub image checklist** — add new src path in order of appearance
5. Promote `bcard-soon` → `bcard-featured` or `bcard` in `BODY_BLOG_INDEX`
6. Add image files to `assets/blog/`
7. Run `node build.js` → `git add -A` → commit → push
